# Homepage assets

These assets come from the supplied ACE-Brain-0.6 manuscript materials.
PDF figures are rasterized as PNGs so they display directly in GitHub READMEs.

| Asset | Supplied source |
|:--|:--|
| `logo.png` | `logo/ace_logo_2.png` |
| `ace-brain-logo.png` | Supplied `logo.png` ACE-Brain wordmark |
| `brand-header.svg` | Side-by-side layout of the two original logo PNGs |
| `overview.png` | `figures/overview.pdf` |
| `pipeline.png` | `figures/pipeline.pdf` |
| `data-scaling.png` | `figures/fig_scaling_avg.pdf` |
| `robotgrounding-results.png` | `figures/fig_capability.pdf` |
| `ACE_Brain_Grounding.pdf` | Supplied `ACE_Brain_Grounding.pdf` technical report |

Both logo PNGs are copied unchanged. The SVG header embeds them with ACE Robotics
on the left and ACE-Brain on the right. Its white background keeps the black
wordmark readable in dark themes, and a single responsive image preserves the
arrangement on narrow screens.

Figures preserve their original layout and are
rendered at 2,400 pixels on the longest edge (2,000 pixels for the scaling plot).
The technical report is copied unchanged. The README's benchmark table uses the
reported results for GPT, Claude Opus, Gemini, and ACE-Brain-0.6 from Table 1.
