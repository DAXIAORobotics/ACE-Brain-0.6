# Homepage assets

These assets come from the supplied ACE-Brain-0.6 manuscript materials.
PDF figures are rasterized as PNGs so they display directly in GitHub READMEs.

| Asset | Supplied source |
|:--|:--|
| `logo.png` | `logo/ace_logo_2.png` |
| `overview.png` | `figures/overview.pdf` |
| `pipeline.png` | `figures/pipeline.pdf` |
| `data-scaling.png` | `figures/fig_scaling_avg.pdf` |
| `robotgrounding-results.png` | `figures/fig_capability.pdf` |

The logo is copied unchanged. Figures preserve their original layout and are
rendered at 2,400 pixels on the longest edge (2,000 pixels for the scaling plot).
The README's benchmark table uses the active results in `contexts/5_exp.tex`.
